# Fahim Portfolio - Personal Portfolio Website

A modern, responsive personal portfolio website built with ASP.NET Core (.NET 10.0) to showcase my skills, projects, and experiences.

🚀 **Live Demo:** https://fahim-portfolio-oo0u.onrender.com

### ✨ Features
- Responsive Design - Works on all devices
- Modern UI/UX
- About Me, Skills, Projects Section
- Contact Form
- Fast & Lightweight

### 🛠️ Tech Stack
- **Backend:** ASP.NET Core MVC (.NET 10.0)
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **Deployment:** Docker & Render

### 📂 How to Run Locally
```bash
git clone https://github.com/mdfahimra/Fahim_Portfolio.git
cd Fahim_Portfolio
dotnet restore
dotnet run
